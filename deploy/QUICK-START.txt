┌─────────────────────────────────────────────────────────┐
│ 📦 EASIEST METHOD - NETLIFY (2 MINUTES)                │
└─────────────────────────────────────────────────────────┘

1. Go to: https://app.netlify.com/drop
2. Drag this entire 'deploy' folder into browser
3. Wait 30 seconds
4. Get your URL: https://your-app.netlify.app
5. ✅ DONE!

┌─────────────────────────────────────────────────────────┐
│ 🤖 CONNECT TO TELEGRAM BOT                             │
└─────────────────────────────────────────────────────────┘

1. Open Telegram → Chat with @BotFather
2. Send: /newbot
3. Follow prompts (name your bot)
4. Send: /newapp
5. Select your bot
6. Enter your deployed URL
7. Users access: t.me/YourBotName/app

┌─────────────────────────────────────────────────────────┐
│ ❓ TROUBLESHOOTING                                      │
└─────────────────────────────────────────────────────────┘

Problem: Images not showing
→ Check src/assets/ folder exists
→ Clear browser cache

Problem: Modal not opening
→ Check browser console (F12)
→ Look for JavaScript errors

Problem: Telegram bot fails
→ URL must be HTTPS (auto on Netlify/Vercel)
→ Test URL directly in browser first
